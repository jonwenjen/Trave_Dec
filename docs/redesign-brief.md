# Trave_Dec 重新製作 — 設計與攻略簡報（agy / Gemini 3.8 Flash High）

「非修改、重新製作」：以知名旅遊網站的設計語言與 2026 旅遊 UX 趨勢，重做前端視覺與體驗，內容重組並新增「攻略」。資料層（行程、抵達方案、吃喝、日文字卡）可沿用 `src/data/itinerary.js` 的既有資料，但呈現方式全面重做。

## 一、設計方向（參考多個知名旅遊網站）

- **Airbnb**：攝影優先、純白暖底、單一品牌色、近黑暖文字 `#222222`（絕不用純黑）、三層柔影、大圓角（卡片 20px、控制 50%）、DM Sans、負字距標題、雜誌式留白節奏。
- **Google Travel ／ Playbook**：首屏即清晰價值主張＋嚮往感內容＋捷徑；圖片可縮放；減少摩擦。
- **Lonely Planet / Japan-guide**：編輯式攻略、資訊密度、章節錨點導航、清楚標題階層。
- **Klook / KKday**：卡片式景點/行程、價格與評分、收藏/書籤、區塊化篩選。
- **2026 趨勢**：mobile-first、沉浸式視覺＋微互動、可及性（鍵盤可操作、WCAG）、「信任勝於選擇」＝策展式、降低決策疲勞、慢旅行、個人化。

### 設計系統（token）

- 背景：暖紙白 `#faf8f3`（正文區）／純白卡片 `#ffffff`
- 文字：近黑 `#222222` 主、`#6a6a6a` 次、`rgba(0,0,0,0.45)` 弱
- 品牌色（單一）：暖珊瑚 `#e8553a`（CTA、標籤、焦點；只用於重點，不鋪底）
- 深色區塊：深松綠 `#1d3a33`（hero／攻略章的深色面板，配米白文字）
- 字體：標題 **Noto Serif TC（思源宋體）** 營造時尚編輯感；內文 **Noto Sans TC**；數字/拉丁 **DM Sans**（Google Fonts，`display=swap`）
- 圓角：按鈕 8px、卡片 20px、大容器 32px、圓形控制 50%
- 三層柔影：`0 0 0 1px rgba(0,0,0,.02), 0 2px 6px rgba(0,0,0,.04), 0 4px 8px rgba(0,0,0,.10)`
- 留白：章節間大留白（雜誌節奏）；8px 基準網格

## 二、資訊架構（單頁、錨點＋黏性導航）

1. **Hero 首屏**：目的地名＋「10 日滑雪攻略」價值主張、日期/人數/基地速覽卡、CTA 錨點（行程／攻略／吃喝）、嚮往感（以版型與字型呈現，不用假照片）。
2. **總覽**：行程地圖條（Day 1→10 橫向時間軸）、關鍵數字（天數、雪板日、人數、預算）。
3. **每日行程**：垂直時間軸，事件卡（時間/類型/狀態標籤/費用/來源），點擊展開；已過事件灰化。
4. **朋友抵達方案**：12/15 多方案（沿用既有 FRIEND_ARRIVAL_OPTIONS），19:00 前抵達＋緩衝 ✓/⚠。
5. **吃喝**：卡片式（區域＋分類篩選），「吃」「喝／酒吧」分類，評分/來源/營業日。
6. **攻略（新增）**：編輯式長文章節，錨點導航，含：
   - 滑雪攻略：初滑票價、纜車 8:30–16:30、橫手山刻滑、樹冰行程、夜滑
   - 交通攻略：成田→志賀、新幹線 vs 高速巴士、行李宅急便、末班巴士警告、計程車預約
   - 住宿攻略：2307 一泊二食、熊之湯溫泉日歸、退房/寄放
   - 吃喝攻略：各區必吃、酒吧、營業日提醒
   - 行前攻略：雪具託運、旅遊保險、現金/信用卡、SIM/網路
   - 安全攻略：110/119、雪場巡邏、失聯集合點、大雪封路應變
7. **隨身工具**：日文大字卡、情境短句（語音）、緊急電話一鍵撥打。
8. **頁尾**：官方來源連結、資料時效說明、歸屬。

## 三、UX 要求

- mobile-first 響應式；黏性頂部導航＋章節錨點；返回頂部。
- 微互動（hover/focus、卡片浮起、平滑滾動、`prefers-reduced-motion` 尊重）。
- 鍵盤可操作、focus 可見、≥44px 觸控熱區、對比達標。
- 深色模式（沿用既有偏好＋手動切換）。
- 保留：人數分攤、預算、搜尋、篩選、離線 SW、ICS/JSON 匯出、分享連結、重置。
- 時刻票價標「規劃估算／前季參考」＋官方來源連結；不假造即時資料。
