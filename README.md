# Trave_Dec — 泰國甲米跳島浮潛 2027/04

一個 mobile-first 的**單一趟旅程規劃頁**：把泰國甲米的九種走法並排攤開，讓你依浮潛強度、能見度、秘境程度、體力與預算做選擇，而不是被「熱門玩法」推著走。介面為繁體中文，島名保留英文（Koh Rok、Phi Phi、Similan…）。

設計語言為原創實作：深松綠 Hero、單一珊瑚品牌色、思源宋體標題、雜誌式大留白，附深／淺模式切換。

## 現在能做什麼

- **十四種方案**並排比較 — 甲米 7 天六案 ＋ 9 天三案，普吉另 5 案
- **2026 前季價格**（`#pricing`）：十四案統一壓縮到 7 天 6 晚，用同一個價格基準比較
- **改由桃園出發**的完整重評：TPE→HKT 直飛 4h25m vs TPE→KBV 經曼谷 13–16h
- **2025 潛水法規專區** — 泰國自 2025/4/22 起強制浮潛穿救生衣等全國性法規
- **2026/27 超級聖嬰評估**與三個日期窗口比較
- **珊瑚保護五禁**、跨方案法規檢查清單（可勾選並保存本機）
- 費用試算與人數連動、離線可用、深色模式

### 普吉與離岸島嶼（`#phuket`）

**為什麼有這個區塊**：桃園出發時，普吉與甲米的交通成本差距是結構性的。
TPE→KBV 無直飛（13–16h，必經曼谷），TPE→HKT 有直飛（4h25m）——差距約 **10 小時**。
這是以高雄為前提時看不到的面向。

**但有硬約束**：TPE→HKT 每週僅約 **2 班**，不是每日班表。日期必須配合航班，
所以每一案的「日期前提」都寫在卡片上。2027/04 班表尚未公布。

| 案 | 名稱 | 強項 |
|---|---|---|
| P1 | 七日・普吉經典（直飛最短） | 移動負擔最低，基地不變 |
| P2 | 七日・Koh Yao 秘境駐紮 | 秘境 ＋ 費用親和，**免公園費** |
| P3 | 八日・自由潛水專程（拿 AIDA 證照） | 普吉唯一無可取代的一項 |
| P4 | 九日・普吉進、Similan 出（交通最省） | 同時吃到 Racha 20–30m 與 Similan |
| P5 | 八日・全離岸島嶼（涵蓋最廣） | 5 個海域，且無一需超過 90 分船程 |

**兩個必須知道的點**：

1. **Similan 從普吉出發是常見誤區** — 除非飯店主打「普吉出發快艇」，
   否則業者會用車把你載回 Thap Lamu 碼頭，等於多花 2 小時車程換同一趟船。
   Similan 本質是 Khao Lak 行程，而 Khao Lak 離甲米機場只要 1.5 小時。
2. **自由潛水普吉反而更強** — SSS Phuket 是島上唯一四系統中心（AIDA／SSI／
   Molchanovs／PADI），AIDA 1 僅需 1–2 天；Racha Noi 能見度 20–30m 是共識訓練點。
   相較甲米／蘭塔的導潛日（同時段上限 2 人），這裡給的是完整教學與認證。

### 甲米九案

**7 天六案**（`2027-04-06 – 04-12`）：

| 案 | 名稱 | 特色 |
|---|---|---|
| 1 | Similan 能見度優先 | 能見度頂點，秘境與自由潛水機會少 |
| 2 | Trang 秘境深度 | 秘境價值滿分，移動負擔高 |
| 3 | 蘭塔駐紮（可加自由潛水） | 住島上能反覆下水，適合練自由潛水 |
| 4 | 全海域六區 | 涵蓋最廣，但每天都在移動 |
| 5 | 三區精華 | 放棄 Phi Phi 與 Hong，專注 Similan ＋ 翡翠洞 |
| 6 | 翡翠洞專注・零移動 | 最省、體力最友善，但只去一個海域 |

**9 天三案**（放寬兩個前提）：

| 案 | 名稱 | 特色 |
|---|---|---|
| 7 | 九日・能見度與秘境兼得 | 7 天做不到的組合：Similan ＋ 翡翠洞同時吃到 |
| 8 | 九日・蘭塔駐紮反覆練習 | 住 5 晚，唯一能真正練到自由潛水進步的安排 |
| 9 | 九日・全海域慢慢走 | 六案的所有海域，但每個區都住夠玩夠 |

### 放寬的兩個前提

七案原本都鎖死在 7 天，導致 Similan（船程 1.5–2 小時）與翡翠洞（陸路 2–3 小時）必須二選一。三案放寬：

1. **天數 7 → 9** — 多出的兩天是給船程與緩衝，不是多排景點
2. **雙點進出（open-jaw）** — 高雄 → 曼谷 → 甲米（KBV）進，回程從 Trang（TST）出，讓「南下 Trang」從折返變成出口

代價直接寫在卡片上：多 2 晚住宿與餐費、open-jaw 票價通常較貴、行李需在 Trang 重新整理。

## 三個會改變決策的前提

1. **高雄無直飛甲米**，KHH→KBV 一律經曼谷轉機
2. **奧南→蘭塔渡輪每年 5 月停駛**（僅 10 月–翌年 4 月）— 5 月案被降級的主因
3. **Similan 僅 10/15–5/15 營運** — 5 月案同樣因此降級

兩個都不存在於 4 月，這是 4 月勝出的結構性理由。

## 2025 潛水法規

《Measures for the Protection of Coral Reef Resources from Diving Tourism Activities, B.E. 2568》，
自然資源與環境部發布，**2025/4/22 生效**，依《海洋與海岸資源管理法》執行至少 5 年，適用全國海岸線。

- 浮潛者**必須穿救生衣**，除非持有認可的自由潛水或水肺證照
  （**AIDA 2 符合；AIDA 1 是一日入門體驗，不符合**）
- 浮潛者**必須與合格業者同行** — 這讓「自行在碼頭找船」成為灰色地帶
- 礁面上方保留 2m、督導比例 1:20、活動前簡報
- **水下攝影**須 Advanced Open Water 以上或 40 潛記錄 — 自由潛水證照不解鎖拍照
- 「珊瑚礁區」包含**死珊瑚**、柳珊瑚海扇與人工礁
- 業者罰則最高 ฿200,000

## 明確不做（避免誤導）

- **不顯示即時天氣／海況／船班狀態**。2027 年 4 月的實際資料尚未公布，任何「看起來即時」的數字都會是誤導，因此刻意不接 API、也不假造。
- 所有船班、潛店課表、票價與公園費一律標為**前季參考／規劃估算**，附官方來源連結。
- ONI／TMD 資料研究於 2026-09-26，需在 **2027 年 3 月重新查證**。

## 技術

- **Vanilla JS + Vite** — 無框架、無 runtime 依賴
- **PWA** — 離線可用、深色模式、service worker
- **157 個測試**（`node --test`）
- mobile-first、熱區 ≥44px、清楚 focus、`prefers-reduced-motion`

### 評分系統的兩個修正

`docs/krabi-all-plans-reassessment.md` 記錄了重評過程，其中兩項是評分系統本身的 bug：

1. **日期窗口字串軸未正規化** — `windowAxisScore` 對「Similan 季內」等狀態軸回傳 0–5 的原始碼值，卻被當成 0–100 平均，導致這兩項決定性優勢的權重只有數字軸的四分之一。修正後 4/6 窗口從 64 → 88。
2. **法規負擔線性累加** — 原本用 `marineAreas.length` 計算，讓「只去一個海域」自動接近滿分，把真正有內容的多區方案壓下去。改為固定基數 ＋ 點位本身的額外要求。

## 開發

```bash
npm install
npm run dev      # 本機開發（Vite）
npm test         # Node 內建測試（157 個）
npm run build    # 產出 dist/
npm run preview  # 預覽建置結果
```

Vite `base` 已設為 `/Trave_Dec/`，對應 GitHub Pages 專案頁路徑。
