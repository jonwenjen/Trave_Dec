# Trave_Dec — 泰國甲米跳島浮潛 2027/05

一個 mobile-first 的**單一趟旅程規劃頁**：把泰國甲米七日跳島浮潛的五種走法並排攤開，讓你依浮潛強度、雨季風險與預算做選擇，而不是被「熱門玩法」推著走。介面為繁體中文，島名保留英文（Koh Rok、Phi Phi…）。

設計語言為原創實作：深松綠 Hero、單一珊瑚品牌色、思源宋體標題、雜誌式大留白，附深／淺模式切換。

## 現在能做什麼

- **三個決定性前提**：置頂顯示、而非埋在細節裡——
  1. 高雄**無直飛甲米**，KHH→KBV 一律經曼谷轉機
  2. **2027/05 是季風過渡期**（乾季 11–4 月，5 月起進雨季），船班可能臨時取消
  3. **奧南→蘭塔渡輪每年 5 月停駛**（僅 10 月–翌年 4 月），5 月只能陸路 3–4.5 小時

  這三點正是五案分化的主軸，不是裝飾。

- **五種方案卡**（點擊展開完整 7 日行程）：
  - **A 全浮潛跳島** — 基地不搬家，浮潛點最多（12–16 點）
  - **B Phi Phi 過夜＋四島** — 唯一住島上的一案，Ton Sai 夜間是亮點
  - **C 蘭塔駐紮・礁石型** — Koh Rok 水色天花板，代價是陸路進出
  - **D 遠端大島探險** — Surin 保育區，風險最高（想衝 Similan 須 5/10 前抵達）
  - **E 雨季保險型** — 出海 2–3 天，2–3 天全天候陸備

  每案顯示浮潛點、海上天數、基地、搬運次數、船取消後可替代性、前季團費與雨季風險等級；雨備日明確標記。

- **並排比較表**：7 個軸可切換（浮潛點數／海上天數／住島上／搬運基地／5 月雨季風險／船取消後可替代性／前季團費），每軸自動標出最佳方案（★）。

- **費用試算**：出行人數 1–20 即時重算單人與全團費用，可勾選「含機票」。匯率明示為**可自行調整的規劃假設值**。

- **季風過渡期應變對照**：6 種狀況（船班取消、改程、誤以為渡輪有班、暈船、受傷、連續降雨）→ 建議動作。

- **國家公園入場費**：6 筆含季節性（Similan／Surin 僅 10/15–5/15 季），附官方來源。

- **訂票前待查證清單**：6 項可勾選、存本機，附完成度百分比。

- **離線**：service worker + web manifest，首次載入後核心內容可離線開啟。

## 明確不做（避免誤導）

- **不顯示即時天氣／海況／船班狀態**。2027 年 5 月的實際資料尚未公布，任何「看起來即時」的數字都會是誤導，因此刻意不接 API、也不假造。
- 所有時刻、船班、票價與公園費一律標為**前季參考／規劃估算**，附官方來源連結。
- **Similan／Surin 季末（5/15）與瑪雅灣季節性關閉（8/1–9/30）**如實標為「2027 待確認」。
- 免簽與 TDAC 標示「須查證最新規定」。

## 開發

```bash
npm install
npm run dev      # 本機開發（Vite）
npm test         # Node 內建測試（43 個測試）
npm run build    # 產出 dist/
npm run preview  # 預覽建置結果
```

Vite `base` 已設為 `/Trave_Dec/`，對應 GitHub Pages 專案頁路徑。

## 專案結構

```
src/
  data/krabi.js        五案資料、三前提、公園費、應變表、待查證清單
  krabi-helpers.js     純函式（費用試算、風險排序、比較矩陣、清單進度）
  krabi-ui.js          UI 層（渲染、互動、localStorage）
  main.js              進入點：主題切換、離線徽章、SW 註冊
test/krabi-helpers.test.js
docs/krabi-2027-05-plans.md   規劃全文（含五案逐日與決策理由）
```
