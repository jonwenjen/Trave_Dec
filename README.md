# Trave_Dec — 普吉與安達曼海跳島浮潛 2027/03/29 – 04/05

一個單一趟旅程的規劃頁：**泰國普吉與安達曼海跳島浮潛**，11 個方案並排比較。

## 現在能做什麼

- **11 個方案**並排比較 — 熱門路線（Phi Phi、Racha、Similan）與冷門秘境
  （Koh Yao Noi、Koh Haa、Koh Tachai、Koh Maphrao）並列
- **1 個全程極致跳島方案** — 6 天出海、10 座點位、含 2 晚 Koh Miang 國家公園過夜
- **雙向夜航的關鍵效果** — 3/29 晚上出、4/5 晚上回，實際有 **7 個完整白天**
- **逐案逐日行程** — 卡片可展開，含出海日、點位、能見度與人氣評級
- **每人費用試算** — 機票、托運行李 20kg、船資、住宿、公園費、餐費分項
- **優缺點並列** — 每案都有，不是只寫賣點

## 交通前提

| | |
|---|---|
| 出發 | 2027-03-29（週一）晚上，桃園 TPE 或高雄 KHH |
| 回程 | 2027-04-05（週一）晚上，回桃園或高雄 |
| 機場 | 皆為普吉 HKT |
| 實際可活動 | **7 個完整白天（3/30 – 4/5）** |

夜航讓出發與回歸日都變成「交通日」，在泰國的時間比一般 7 天排程多一整天。

**宋干節 2027 為 4/13–15，不在本次行程內。** 4/6 Chakri Day 落在回程抵台日。

## 價格說明

所有價格為 **2026-09-27 查得的當期價**（8–9 月航班、當前船班報價），
**不是 2027-03 的價格**。建議 **2027-02-25** 重新查證。

- 每人報價**含機票與托運行李 20kg**（廉航報價通常不含托運）
- 整團費用（船資、住宿、公園費）由人數分攤，因此人數越多每人越便宜
- 匯率假設：1 THB ≈ 0.093 TWD（可調整規劃假設）

## 開發

```bash
npm install
npm test        # node --test，22 個測試
npm run dev
npm run build
```

架構：
- `src/data/destinations.js` — 20+ 座島嶼的人氣、能見度、船程、公園費
- `src/data/reeval.js` — 11 個方案的逐日行程與價格
- `src/helpers-reeval.js` — 純函式：分攤、彙總、比較
- `src/ui-reeval.js` — UI 渲染
- `test/reeval.test.js` — 測試先行

## 技術

- Vite + 原生 JS，靜態網站，部署至 GitHub Pages（`base: '/Trave_Dec/'`）
- 深淺模式（`prefers-color-scheme` + 手動覆寫並持久化）
- Service Worker 離線支援
- 觸控熱區 ≥44px、`focus-visible`、`prefers-reduced-motion`

## 時效與免責

所有機票、船班、船價、住宿與公園費均擷取自 2026 年 9 月之公開資料與當期報價，
作為行前規劃估算參考，非即時保證資訊。2027 年 3 月的實際班表與海況尚未公布。
本站刻意不連接即時天氣、海況或船班 API。
